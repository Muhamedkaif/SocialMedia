Social Media Application

A full-stack social media application that allows users to register, log in using session-based authentication, create posts with images, and manage their profiles.
The application is built using Spring Boot, React, MySQL, and Cloudinary for cloud-based image storage, and is fully deployed.

✨ Features

🔐 User Authentication using Session-Based Login

👤 User Registration & Profile Management

🖼️ Image Upload using Cloudinary

📝 Create, View, Update, Delete (CRUD) Posts

🧾 RESTful APIs

🌐 Responsive Frontend

☁️ Deployed Full-Stack Application
